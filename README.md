# 山东专升本计算机真题来源笔记

以2020—2026年山东专升本计算机真题为线索，逐题提取知识点，再按教材目录归档。

## 整理规则

- 保留教材第1—11章的章节编号与结构
- 2020年65题、2021年60题、2022年75题、2023年70题、2024年70题、2025年60题和2026年60题，共460道真题来源，合并为220条知识笔记
- 2020年未命中第11章，不虚构内容；2025年和2026年覆盖教材全部11章
- 题号只用于追溯来源，不把网页做成题库或练习系统
- 不按年份拆分学习；相同知识点合并，年份与题号只作为来源标记
- 每条知识笔记都可打开演示；新交互由独立状态模型驱动，旧场景持续按实际结果验证和改进，不把能加载视为质量保证
- 操作题还原 Windows 10 / Office 2016 的对象、入口、步骤顺序、参数变化与错误后果
- 概念题采用可直接操控的模型、仪表、时间线、沙盘或动态关系图帮助理解和记忆
- Office题统一按Office 2016整理，其他内容按现行考试要求或标准概念校正
- 概念与操作统一按现行考纲、教材目录和官方标准功能表述

## 页面结构

- 独立章节页：`chapter1.html` 至 `chapter11.html`
- 以教材11章为唯一主目录，章节页可从页首直接切换
- 窄栏连续阅读、本章搜索、章节切换、本章目录、折叠来源与按需加载演示

线上版本：[打开计算机系统笔记](https://mobius608955255-dev.github.io/computer-interaction-notes/?v=33)
