# 山东专升本计算机交互笔记

面向山东专升本计算机公共课的手机端优先交互学习网站。

## 内容范围

- 第一章：计算机基础与计算思维，重构为 24 个模块、15 个可操作实验
- 第二章：Windows 10，共 16 个模块
- 第三章：Word 2016，共 20 个模块
- 第四章：Excel 2016，共 22 个模块

- 第一章 24 个模块可独立标记为未学、不确定或已掌握

- 真题陷阱判断、结果诊断和操作实验
- 32 道高频章节自测题
- 自动保存的学习进度与错题本
- 四章快速切换、章节检索和移动端适配
