## 整理规则

- 保留教材第1—11章的章节编号与结构
- 2020年65道题和2026年60道题完整覆盖，共整理为100条知识笔记
- 2020年未命中第11章，不虚构内容；2026年覆盖教材全部11章
- 题号只用于追溯来源，不把网页做成题库或练习系统
- 不按年份拆分学习；相同知识点合并，年份与题号只作为来源标记
- Office题统一按Office 2016整理，其他内容按现行考试要求或标准概念校正
- 旧题答案与现行口径冲突时，不保留旧答案
